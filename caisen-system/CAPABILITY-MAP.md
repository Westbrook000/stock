# Capability Map: 蔡森量价股票分析系统

## 2026-10-27 需求修订状态

本轮已澄清并写入下列修订，整合后的规格已获用户批准并授权实施：

- 每次扫描完整分析所选市场范围内的标的与全部活动形态；形态/行动筛选只在扫描结果上执行。
- 行情更新不保留恢复能力、恢复 API 或持久化续跑状态；中断后重新启动整次刷新。当前运行中的进度和结果仍可查看。
- 卖出只表示“如持有可考虑退出”；不接账户、不采集持仓，也不提供做空指令。
- 删除行情刷新时的旧文件校验、哈希快照和刷新清单；分析结果数据版本标识保留，用于追溯输入行情版本。

## 目标与当前基线

把现有的形态研究原型维护为可解释的股票与 ETF 分析系统：对每个标的和周期识别活动形态阶段，并给出买入、持有、卖出提示或等待建议及其证据。建议是研究辅助，不连接券商、不自动下单。现有本地行情、12 招来源审计（10 招活动规则）、FastAPI 页面和模拟接口作为基线；不预设必须推倒重写。

## 建议构建顺序

`source-rules` 与 `market-data` 并行 → `pattern-engine` → `decision-engine` → `simulation-validation` → `analysis-workbench`。

## 端到端系统功能

用户从一个本地分析工作台完成“扫描 → 看形态证据 → 看买卖建议 → 定位历史形态 → 模拟验收”的流程：

1. **行情范围与状态**：读取当前本地股票及全部 ETF 行情；以日线、周线分别分析。标明数据截止日、来源/版本和已知质量问题，缺数据或量价口径不明时提示数据不足。
2. **一键全量市场扫描**：用户点击一次“全量扫描”，覆盖本地全部股票和 ETF 文件、日线与周线，并对每个标的识别全部十种活动形态；形态类别不缩小扫描范围。展示扫描进度和完成状态。结果按标的合并为一行，同时呈现日/周判断和冲突，不让同一标的重复占据多个排名位置。每行显示名称/代码、品类、决策状态和近期迷你 K 线图。
3. **买入优先排序与结果筛选**：默认将满足买入条件、当前仍有可执行空间的标的排在前面；候选之间按可解释的形态确认、量价证据、风险/目标空间、价格位置、数据完整性及日周关系排序。扫描完成后可按买入/等待等行动及当前形态多选筛选；筛选只作用于已完成结果，不会重新扫描。非买入项显示等待、持有、卖出提示或数据不足。排序是规则优先级，不是上涨概率；精确评分和并列规则由 `decision-engine` 规格定义。
4. **形态详情**：点击扫描行或迷你图直接打开对应标的详情，默认定位到最新行情，展示该股票/ETF的当前日线、周线形态和买卖分析。详情包括 K 线与成交量、关键拐点/颈线/整理边界、触发与失效位置、测幅目标、规则出处、逐项证据以及买卖理由/条件。形成中的候选必须显式标成例如“W底，未确认”，不得伪装成买入信号。
4. **买卖分析**：分别给出日线、周线判断及冲突提示；对形态证据足够的标的形成可解释的买入、持有、卖出提示或等待建议，附触发理由、参考介入/退出条件、结构失效位和目标。系统不输出未经校准的上涨概率。卖出提示仅为 `SELL_IF_HELD`，不连接账户或输出做空指令。
5. **已结束形态图表定位**：详情页列出已结束形态；点击某一形态后，在该形态所属日/周 K 线上标出结构点、颈线/边界、确认点和结束原因/目标，并自动定位到覆盖该结构起点至结束点的窗口。
6. **模拟执行**：将买卖建议交给 Backtrader 在本地历史行情中模拟，展示委托/成交、持仓、现金及交易记录；按用户已确认的范围不计交易费用。此阶段验收撮合与账目，不验证策略盈利效果。
7. **运行边界**：本地服务/API，默认不接券商、不自动下单；系统输出研究辅助判断，由用户复核决定是否交易。产品不提供人工复核或用户可调用的历史回放。

其中 `source-rules` 只负责原书规则来源和机器规则目录；它本身不会完成扫描、判断页面或模拟功能。每个后续模块在自己的规格中细化页面、接口和验收标准。

## 当前边界

- 沿用本地现有行情作为首版数据来源；历史缺口、复权和量能单位等质量限制须随信号显示。
- 覆盖股票、全部本地 ETF，以及日线、周线；两个周期分别判断并展示冲突。
- 识别系统先给可解释建议，不自动交易；本轮先完成形态校准和 Backtrader 模拟验收，策略效果验证另行安排。
- 形态规则、模型/算法候选和人工修正要能区分并追溯版本。

## 本轮仍采用的已确认边界

- 保留现有本地页面和 API 工作流；本轮只澄清并更新规格，实际代码改动须在规格批准后规划和实施。
- 行情更新包括用户触发的刷新和每天上海时间 05:00 的本地自动化；刷新任务没有恢复/续跑能力。刷新成功只代表数据源返回并完成字段/日期格式整理，不代表 OHLCV 数值或历史覆盖已验证。
- 分析结果保留独立数据版本标识；不保留行情刷新旧文件比较哈希、旧 CSV 快照或恢复任务检查点。
- 策略效果验证继续暂缓；Backtrader 零费用只承担模拟撮合与账目功能验收。
- 当前形态规则参数继续使用；删除人工标签/校准工具与数据后，不得把现有阈值描述为经过统计校准。
- 保留检测器前缀因果性检查；它只验证新增未来 K 线不会改写已知历史结构，不提供用户指定日期的历史回放。
