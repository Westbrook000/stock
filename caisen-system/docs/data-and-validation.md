# 数据、模拟与验收

读取本地 `data/stocks` 与 `data/etfs`，分析结果保留来源、末日和数据版本。更新行情时只整理字段与日期格式，不校验数值、历史覆盖或行数，不保存旧行情哈希/快照/刷新清单。采用临时文件原子替换，单个标的失败时保留其旧文件。刷新进度只在当前进程有效，不支持恢复。

日/周分析独立。2020–2026正式周线按上交所公告交易日历聚合；缺少可信日历或未完成周的数据仅作预览。量能单位、企业行动或标的交易制度未知时展示相关提示。

已结束形态通过当前详情图查看：选择形态后定位到其冻结锚点与结束点，显示结构线、边界和终止原因。这不提供用户指定历史日期的回放。人工复核、盲标、人工校准工具及其记录均已移除。

Backtrader负责模拟撮合，研究账户默认10万元、费用和滑点为零；周线信号用日线撮合。委托仅在下一有效交易日尝试一次；结构止损优先、首目标全额退出，现金与市值必须核对。模拟日期范围继续支持，策略盈利效果验证暂缓。

自动验证保留形态几何正反例、前缀因果性、数据段隔离、完整周判断、决策/排序、历史图表坐标和Backtrader账目检查。前缀检查要求新增未来K线不能改写过去已知的锚点、颈线与确认日。
