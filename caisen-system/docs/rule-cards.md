## 系统解释规则

- 原书所示的示例风险比例和收益区间是作者操作示例，不是本系统经过验证的业绩结论，也不自动覆盖本系统自己的风险约束。
- 原书十二个候选项没有一套通用的固定量能倍数；当前十招规则中的量能字段为空，避免把系统研究参数误标为原书硬条件。
- “形成中/未确认”必须与“价格确认”分开。未确认结构不得展示已解锁测幅目标。
- W/M 与收敛三角形的相邻结构段时长比需 ≤2.5 才进入候选列表。该条件是首轮标注驱动的工程筛选初值，不是原书规则；十例开发样本已参与该阈值调整，须用独立盲标集重新评估。
- 头肩顶/底的左右肩价差除以头部至颈线的垂直高度需 ≤7%。这是规则集 v4 根据开发标签缩窄的工程初值，用来避免肩部过度不对称的候选；不是原书数字，须经独立留出验证。
- 形态方向不是持仓动作。卖出、持有、等待、全市场买入优先级由决策模块确定；本规则库不自动做空、不发券商订单。
- 自动候选与人工标注分开保存；复合结构、旗形边界等需要复核时，界面必须明示。
- `w_bottom_spring` 与 `false_breakout_head_shoulders` 仅保留在原书来源审计及旧规则历史显示中，不属于当前活动目录。
- 整理箱体的四触点、至少10根跨度、`max(0.5 ATR, 5%中位价格)`边界容差、最大6 ATR宽度、80%收盘区间比例与20根回收时限是待校准的工程初值，不属于原书硬规则。
