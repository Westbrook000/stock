01 / RECOGNITION形态识别

算法按因果顺序逐步筛选结构

输入 OHLCV 后，不直接“看图猜形态”，而是提取可复核的拐点、边界和状态。

01 · 行情

清洗与分段

统一日期和 OHLCV；检查异常行、跳空断点和数据来源。结构不跨数据断点。

02 · 拐点

ATR 摆动点

14期 ATR；局部高低点需右侧 2 根 K 线确认，并以 2ATR / 3ATR 两组尺度过滤噪声。

03 · 几何

匹配拓扑

检查 3 点、5 点高低点次序；估计水平/斜颈线、旗形通道和三角边界。

04 · 确认

收盘越线

候选结构先标“未确认”；普通 W/M 不再自动派生破底翻/假突破，须有真实越界与收复证据。

05 · 计划

交易空间

检查结构状态、结构歧义标记、数据质量、固定止损和首目标空间。

因果纪律

拐点有“发生日”与“可知日”

峰谷发生在图上的那天，但程序要等后续 2 根 K 线才确认它是拐点。前缀因果性检查验证新增未来数据不会改写过去已知结构。

计算边界

形态分析窗口

形态详情最多分析 500 根日K、520 根周K；旗形搜索完整窗口并要求五个已确认摆动点、受限回撤和通道边界。

实现依据：caisen/pivots.py · patterns.py · market.py02 / 07
02 / RULE CATALOG10 招活动规则

12 个规则名，共用几何识别骨架

每个识别结果都保留锚点、颈线、突破日期、失效位与目标；不同规则可共享拐点；竞争标签会标记结构歧义，并阻止其直接成为买入计划。

W 底↔M 头
破底翻↔假突破
下飘旗形上涨中继↔上飘旗形下跌中继
头肩底↔头肩顶
收敛三角形底部↔收敛三角形头部
W / M 结构

比较低点 / 高点，再找颈线

允许双底不等高，也允许斜颈线。突破前只显示“W底，未确认”；趋势方向需结合突破和失效判断。

三角 / 旗形

检查收敛与前序推动波

三角形检查边界斜率、触点与交点位置；旗形检查先前推动波、逆向整理和后续突破条件。

请这样理解覆盖范围：活动十招具有识别入口，原书十二招仅保留来源审计；程序当前以标准几何结构为自动识别范围，复合形态、缺少可验证证据的变体保留结构歧义提示。原书图例并不都能转换成无歧义的数值条件。
结构定义以原书规则审计与 docs/rule-cards.md 为准03 / 07
03 / EVENT LIFECYCLE确认与失效

“形态出现”与“允许介入”是两件事

识别器给结构状态；交易计划再做风险与空间筛选。

形成中锚点与拓扑满足部分规则，尚未收盘突破。界面显示“W底，未确认”。
价格确认收盘价首次穿越当时冻结的颈线/边界，保存确认日期和突破量比。
失效价格重新越回失效线，或数据分段变化使结构不能继续追踪。
结构歧义程序保留结构证据；存在竞争解释时返回等待。
W 底测幅颈线中间值 − 底部中间值 = 第一段距离；第一目标为颈线 + 距离。
破底翻先破整理区下沿，再收复回区间；箱体上沿可作首个已知目标。
中继结构旗形须突破前波高/低才解锁波段目标；三角突破位置也要符合规则区间。
量价证据程序记录突破日量比；复权与成交量单位未验证时会标“量能未核验”。
当前工程事实：“量能未核验”时仍展示价格形态和证据，但计划标记“等待”，不会进入可考虑买入候选；待来源、量能单位与企业行动口径绑定并核验后，才重新评估交易计划。
量比 = 突破日成交量 / 前 20 根可比日均量04 / 07
04 / DECISION ENGINE从形态到行动提示

通过结构风险与目标空间，才排进买入候选

先定结构失效位，再按当前参考价测算；风险太大或首目标空间太小就等待。

≤ 7%参考买入价到结构止损的计划风险上限
≥ 2R首个有效目标扣费后风险回报门槛；当前零费用基线
结构止损形态失效位减去 0.5 ATR 或两个报价单位缓冲
次日复核只尝试下一有效交易日；开盘价越界或超最高买入价则放弃
可考虑买入等待 / 数据不足持有观察如持有可考虑卖出
扫描排序（逐项透明，不是概率）
  1. 先排通过所有买入硬条件的标的
  2. 同向已确认周期数更多者靠前
  3. 首目标 R 倍数更高者靠前（上限封顶）
  4. 计划风险更低、确认更新者靠前
  5. 最后按代码和品类稳定排序
周期独立：日线和周线各自识别；正式方向冲突时转为“等待”。2020–2026 周线使用上交所官方年度休市公告；2000–2019 年第三方日历及 2027 年以后的日期仍只作预览。空头标签只提示已有持仓复核，不代表做空或自动卖出。
当前费用参数：佣金 0、最低收费 0、滑点 0；仅为用户要求的模拟基线05 / 07
05 / PRODUCT FLOW项目功能与使用流程

从全量扫描，到一只标的的证据复核

工作台把“找候选、看结构、复核数据、模拟执行”串成闭环，不自动连接券商。

全量扫描

按股票/ETF、品类、形态、周期与确认日期筛选。

买入优先

一标的一行；候选靠前，显示状态、价格、告警与迷你K线。

进入详情

点击行或缩略图，载入最新日线/周线结论与形态图。

看计划证据

检查颈线、关键点、确认日、止损、目标和 R 倍数。

历史形态定位

选择已结束形态，在K线图上定位其结构与结束位置。

模拟执行

Backtrader 按下一开盘模拟；零费用；不发真实委托。

数据入口

当前本地行情文件

扫描本地 CSV，保留文件哈希、数据版本、截止日期和质量告警；可主动触发单标的/全市场更新。当前行情快照不代表完整历史市场。

服务接口

独立本地 API 与页面

FastAPI 提供分析、扫描任务、详情、历史形态图表和 Backtrader 接口；默认打开 127.0.0.1:8301。

页面入口：市场扫描 · 形态详情06 / 07
