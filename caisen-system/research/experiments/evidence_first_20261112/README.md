## 当前优化

- 先按独立测试数、跨度、偏差等证据选择第一条边界，再判断其是否突破。不遍历到哪条线今天突破就采用。
- 精确相同的线视为同线。至少共享两个压力触点、且证据时点价差均不足半报价单位时，数值重拟合也视为同线；不再用ATR触线容差合并实质新线。
- 结构日期与压力点相同但几何不同的边界，在形态ID中增加以结构日期为原点的线参数，避免窗口索引偏移及版本冲突。
- 每条线独立审计必要结构和边界均可知后的首次1ATR突破；未被选中时发生过的突破也会消耗该线，不允许后来再次越线冒充首次确认。
- 审计按冻结线及起点缓存，仅追加新K线；缓存中未来事件不会在较短前缀返回。
- 六个月底部门槛、1ATR突破、2ATR压力点、实际成交8%/20%等不变。
