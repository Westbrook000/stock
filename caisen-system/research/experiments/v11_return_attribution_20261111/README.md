# v11收益下降归因与修复实验

所有候选源码均隔离在state/v11-return-attribution-20261111/variants；生产代码未改动，不将候选标为原始v8。

固定上一轮100股票、冻结行情、2026-10-30截止日，以及Backtrader每账户10万元、次日开盘、8%止损、20%止盈、零费用、期末退出。

8个独立工作进程先对确定性开发面板做单因素筛查，再对选定修复做100账户复验。面板由种子20261111随机10标的及000538、600633组成，不是独立留出样本。

## 实验组

|实验|改变|采用限制|
|---|---|---|
|no_phase_consumption|停用等价颈线消耗|诊断组，可能恢复重复买点，不直接采用|
|no_global_premature_failure|撤去旧线失败终止整组底点的分支|同线消耗规则仍保留|
|v9_selection|只恢复748d3d01的候选选择循环|不是完整v8；不允许以盈利为由保留图线与状态不一致|
|moving_support|确认后固定支撑改回逐日斜线支撑|不改变实际8%/20%持仓退出|
|no_right_shoulder_guard|停用新增右肩完整性检查|诊断组，不把收益当作形态真值|
|no_prefix_cache|禁用前缀DataFrame缓存|应保持完整信号、成交和权益一致|
|precise_boundary_identity|仅数值相同的冻结直线视为同线|不同线不因触线容差被合并；同线新增触点仍不重发|
|scoped_phase_repair|组合旧线失败作用域修复与精确线身份|报告交互，不把组合收益归因给某个单项|

仅在no_global_premature_failure、precise_boundary_identity、scoped_phase_repair中，按面板收益率、随后胜率排序选出一个进行100账户复验。单因素面板结果不冒充100账户归因。保留所有成功/失败结果，不自动将开发高收益候选切换为生产。
